## 🎨 渐变色

### 火焰渐变（推荐品牌渐变）
```
色值：#FF6B35 → #FFD93D
角度：135°
代码：linear-gradient(135deg, #FF6B35 0%, #FFD93D 100%)
```
**适用：** 品牌主视觉、按钮悬停、Github README 封面

### 灵魂渐变
```
色值：#4ECDC4 → #2D1B4E
角度：180°
代码：linear-gradient(180deg, #4ECDC4 0%, #2D1B4E 100%)
```
**适用：** 深色模式背景、科技感元素

### 熔岩流动渐变
```
色值：#E63946 → #FF6B35 → #FFD93D
角度：90°
代码：linear-gradient(90deg, #E63946 0%, #FF6B35 50%, #FFD93D 100%)
```
**适用：** 特殊视觉场景、熔炉效果

## 🎯 色彩使用规范

### 对比度要求
- 正文文字与背景对比度 ≥ 4.5:1（WCAG AA）
- 大标题与背景对比度 ≥ 3:1
- 深色文字使用 #F5F5F5，白色文字使用 #333333

### 色彩比例（60-30-10法则）
```
主色（火焰橙）：10% — 用于关键强调点
辅助色（灵魂蓝）：30% — 用于次要元素和功能
背景/中性色：60% — 占据视觉空间
```

## 🔧 工具适配

### Tailwind CSS
```javascript
// tailwind.config.js
colors: {
  'forge-orange': '#FF6B35',
  'soul-blue': '#4ECDC4',
  'night-purple': '#2D1B4E',
  'stardust-gold': '#FFD93D',
}
```

### CSS Variables
```css
:root {
  --forge-orange: #FF6B35;
  --soul-blue: #4ECDC4;
  --night-purple: #2D1B4E;
  --stardust-gold: #FFD93D;
  --cloud-white: #F5F5F5;
  --charcoal: #333333;
}
```

### Python Matplotlib
```python
COLORS = {
```
