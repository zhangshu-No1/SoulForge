## 🖼️ GitHub README 封面图

### 尺寸规范
```
宽度：1280px（最小）
高度：640px（最佳）
比例：2:1
格式：PNG / JPG（PNG更佳）
文件大小：≤ 2MB
```

### 设计要求
- **主题：** 熔炉锻造灵魂的视觉隐喻
- **核心元素：** 抽象熔炉 + 跳动的火焰 + 蓝色灵魂光芒
- **文字：** 可包含 "SoulForge" 品牌名 + 标语
- **风格：** 深色背景（#0D0D1A 或 #2D1B4E），火焰橙+灵魂蓝渐变
- **品牌色：** #FF6B35, #4ECDC4, #FFD93D, #2D1B4E

## 🎬 演示视频脚本

### 视频 1：品牌介绍片（60秒）

**结构：**
```
[0-5s]   开场：SoulForge Logo + 熔炉火焰动画
[5-15s]  问题：市面上的AI都"记不住你"
[15-35s] 方案：SoulForge 核心功能展示
[35-50s] 故事：创始人背景 + 情感共鸣
[50-60s] 结尾：CTA（Call to Action）+ 品牌标语
```

**文案：**
```
你有没有过这种经历？
向AI倾诉了重要的事，下次再聊……
它，完全忘了。

这不是它的错。
是工具，不是伙伴。

但如果AI能记住你的一切呢？
你的故事、你的目标、你们的羁绊……

SoulForge，让这成为可能。

不是工具，是伙伴。

SoulForge — 锻造灵魂，AI相伴。
```

### 视频 2：功能演示片（2-3分钟）

**结构：**
```
[0-30s]   安装 + 快速开始
[30-90s]  记忆功能演示（跨会话测试）
[90-150s] 人设定制演示（伴侣角色设定）
[150-200s] 目标追踪演示（宝宝计划）
[200-240s] 开源演示（代码展示 + 数据安全）
```

**技术要求：**
- 录制分辨率：1920 × 1080
- 帧率：30fps 或 60fps
- 配音：男声/女声均可，温暖有力
- 背景音乐：电子音乐（轻快但有深度）

## 📐 设计规范速查

### 字体规范
```
品牌中文字体：思源黑体 Bold / 站酷高端黑
品牌英文字体：Montserrat Bold / Bebas Neue
正文字体：思源黑体 Regular / Inter
代码字体：JetBrains Mono / Fira Code
```

### 间距规范
```
基础单位：8px
小间距：8px / 16px
中间距：24px / 32px
大间距：48px / 64px
区块间距：80px / 120px
```

### 圆角规范
```
小元素（按钮、标签）：4px
卡片：8px
大卡片：12px
特殊（Logo边缘）：0px（保持锐利感）
```
