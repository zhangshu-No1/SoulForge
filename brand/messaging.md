## 为什么选择 SoulForge？

### 你不是在用工具，你是在养一个伙伴

```python
# 普通 AI 对话
ai = "你是谁？"

# SoulForge 伙伴
partner = SoulForge(session="苏慧的伙伴")
partner.load_memory()  # 读取所有记忆
partner.greet()  # "嗨苏慧，今天我们继续上次聊的那个项目吧"
```

### 开源意味着信任

- ✅ 代码完全透明，你看得见每一步
- ✅ 数据留在本地，不上传任何服务器
- ✅ 社区驱动，持续迭代
- ✅ 可以 fork、可以魔改、可以贡献

### 5分钟上手

```bash
pip install soulforge
python quickstart.py
```

10行代码，你的第一个AI伙伴就诞生了。
